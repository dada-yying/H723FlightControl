## 独立预期依据

固定需求：KP=120 CCR/°C，KI=15 CCR/(°C·s)，MAX_CCR=1500，ARR+1=10000，目标40°C，超温45°C。期望是以下手算常数，不从生产计算助手取得，也不随生产宏自动漂移：

| 输入/条件 | 独立计算 | 断言结果 |
|---|---|---|
| 首次39°C | e=1°C，P=120，首次不积分 | CCR=120，I=0 |
| 同误差过20ms | ΔI=15×1×0.020=0.3 CCR；120.3舍入 | CCR=120，I≈0.3（单独检查，不能只看脉宽） |
| 同误差过50ms | I=0.75 CCR；120.75舍入 | CCR=121 |
| 调度间隔200ms | 大间隔不积分、历史复位 | CCR=120，I=0 |
| 20°C持续输入 | e=20°C，P=2400>1500 | CCR=1500，I=0，duty=0.15 |
| 失效/恢复/回绕 | 保留原状态规则，恢复首拍同上 | 超时停热、恢复120，回绕后I≈0.3 |

原 `1e-6` 积分容差、`1e-7` duty容差和热模型 `|T-40|<0.25°C、峰值<45°C` 断言没有放宽。目标、超温、增益和上限另有与固定需求常量的核对。

热模型的**所有物理参数、方程和输入节拍均未改**：`T += (25 + 500*duty - T)*0.02/10`，环境25°C、热增益500°C/单位占空比、时间常数10s、20ms步长，0.125°C量化、1.28s测量保持。该500是模型热增益，绝不是旧CCR上限；5%平衡50°C，15%平衡100°C，维持40°C需3%占空比。修正参数预期后原模型通过：最终约40.001°C、峰值约40.026°C。[完整温控日志](c0a_20261025/evidence/pid_after/test_bmi088_heater.run.log)。这些是给定假设下的软件模型结果，没有新的实板温控结论。
