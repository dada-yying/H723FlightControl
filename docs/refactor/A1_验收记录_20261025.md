## 修复选择与全部写方

选用**短临界区覆盖整个RC检查/提交事务**，没有引入代次协议、配置框架或新调度机制。原RC检查逻辑只移动到私有 `EscPwm_UpdateFromRcLocked`，去掉函数名/`static`差异后正文与基线完全相同；所有早退仍经过公共入口的统一退出临界区。

| 写方/路径 | 当前调用条件及本批处理 |
|---|---|
| EscPwm_Init / memset / ForceMinimumInternal | main启动阶段、调度器启动前；保持原初始化和PWM启动流程，不在新增临界区内调用HAL_TIM_PWM_Start/Stop |
| RcTask → EscPwm_UpdateFromRc | 唯一armed=1及中位资格写方；公共入口先taskENTER_CRITICAL，再执行全部资格检查/中位状态/提交，最后统一taskEXIT_CRITICAL |
| FlightControl_Run / OnTaskTimeout → EscPwm_ForceMinimum | 实际运行中的另一安全写方；短临界区覆盖四路最低命令、armed/资格清除及诊断更新 |
| EscPwm_Disarm | 当前无生产调用，保留API，转调同一受保护的ForceMinimum，理由/计数/最低输出不变 |
| SetAllNormalized的未初始化/未解锁分支 | 能调用私有最低输出助手，但当前生产中无调用；保留已有串行接口行为，不宣称对任意新上下文/重入提供并发保证 |
| SetMixedNormalized | 唯一实际电机提交路径，在飞控任务；RC任务不能抢占它，没有ISR写电机安全状态。未改其浮点限幅/转换，不顺带修复F2 |

实际运行中的RC/飞控安全写方现在由同一FreeRTOS临界区规则互斥。初始化和未使用的兼容API按实际调用条件区分，没有把测试夹具直接写全局状态当作生产写方。未新增ISR或故障处理器调用ESC接口，也没有实现CPU故障停机方案。

为什么不只锁armed写入：如果中位资格/低油门检查仍在锁外，超时可在检查后清除资格，恢复后仍会使用过期检查。当前入口在检查前就屏蔽任务抢占；若超时恰在原窗口到期，它在退出临界区后执行并清除刚提交的armed和中位资格。恢复传感器不会恢复旧资格；必须重新满足现有中位→高位、低油门、启动条件。

RC策略未变：failsafe立即无效、lost不刷新好帧时间/有效期内保持原目标、静默100ms；没有采用旧专项20ms规则，没有添加新的RC帧新鲜度/回放契约。PID、滤波、温控、协议、任务优先级、采样频率、golden和转换器算法均未修改。

## 旧/新差分与调度可达性

**原交错可达：** 当前控制任务High=40，RC AboveNormal=32，抢占开启；控制等待5ms，watchdog门限10ms。最后成功控制为t0，+5ms检查尚未超时，随后再次等5ms。中位帧可在+6ms完成，高位帧在+9ms末尾完成（25字节、100kbaud/8E2线路约3ms）。RC通过检查时遇到+10ms SysTick，控制任务可抢占并锁定，RC随后提交。不是用低优先级BMI任务抢占RC。依据为 `Core/Src/freertos.c:83–94,233–273`、`FreeRTOSConfig.h`、实际BASEPRI port及 `flight_control.c:324–345`。

先在本次检出重现原审计F1，再编辑生产代码：[旧实现编译/运行记录](a1_20261025/evidence/f1_before.json)、[四路输出日志](a1_20261025/evidence/f1_before.run.log)。移除单一观察点可逐字还原当时函数体，原实现退出1；超时先得到armed=0，RC恢复后armed=1，传感器恢复后四路均为0.5/1500µs。

新增专项编译真实ESC翻译单元与真实FlightControl函数；输入/计时器/RTOS是模型。生成器只在唯一armed提交前插入一条观察调用，移除后逐字节恢复来源文件，记录SHA256。模型严格断言超时任务只在临界区深度0执行；如果该点被屏蔽，仅置pending，在最外层退出后执行真实 `FlightControl_OnTaskTimeout`。因此没有强行在新临界区内调用锁定。

同一专项在编辑前失败、编辑后通过：[旧结果](a1_20261025/evidence/before_host/result.json)、[新结果](a1_20261025/evidence/after_host/result.json)、[新完整日志](a1_20261025/evidence/after_host/run.log)。

| 超时位置/恢复 | 旧实现 | 新实现 |
